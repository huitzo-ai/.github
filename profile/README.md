# Huitzo

Huitzo is the marketplace of intelligence systems.

This organization hosts the **self-hosted distribution** of Huitzo for licensed customers. The container images (`ghcr.io/huitzo-ai/*`) are private. Access is granted through a verified Huitzo partner, together with a licence. There is no public source code in this organization.
